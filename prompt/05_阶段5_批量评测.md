## 本Prompt目标

请生成以下模块的完整可运行Python代码：

### 1. src/evaluation/rouge.py
- compute_rouge(reference, prediction) 返回 dict
- 返回字段：rouge_1、rouge_2、rouge_l（各含 fmeasure）
- 使用 rouge-score 库，设置 num_sents=0（非新闻语料模式）

### 2. src/evaluation/run_experiment.py
- ExperimentResult dataclass：
  - split_strategy、embedding_model
  - rouge_1_f1、rouge_2_f1、rouge_l_f1（组内平均）
  - avg_retrieval_time、avg_generation_time、total_wall_time
  - num_questions

- run_single_experiment(config, split_strategy, embedding_model) 返回 ExperimentResult
  - 流程：构建索引（若不存在）-> 批量问答 -> 计算Rouge -> 记录时间

- run_all_experiments(config)：遍历 2切分策略 x 2嵌入模型 = 4组
  - 输出文件：
    - experiments/results/{split}_{embedding}.json（完整参数快照：切分参数、嵌入模型ID、top_k、种子等）
    - experiments/results/summary.csv（4组汇总，列：split、embedding、rouge1、rouge2、rougeL、avg_retrieval、avg_gen、total_time、n_questions）
    - experiments/logs/{split}_{embedding}.log（逐条问答记录，含 retrieval_time、generation_time）
- 随机种子来自 config[seed]，保证可复现

### 3. scripts/run_eval.py
- 入口：读 config.yaml -> 调用 run_all_experiments -> 打印 summary table
- 支持 --seed、--out_dir 命令行参数

### 4. config.yaml 更新
- 新增字段：eval.qa_dataset_path、eval.max_questions（可选，限制评测数量用于快速测试）
