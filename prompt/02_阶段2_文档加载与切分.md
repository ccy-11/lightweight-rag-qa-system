## 本Prompt目标

请生成以下模块的完整可运行Python代码：

### 1. src/loading/pdf_loader.py
- 使用 PyPDF2 提取PDF文本（逐页，处理乱码/空页）
- 返回：List[PageText]，PageText 含 text、page_num、doc_name
- 提供 load_single_pdf(path) 和 load_all_pdfs(dir_path) 两个函数

### 2. src/chunking/base.py
定义：
- 数据类 PageText：text、page_num、doc_name
- 数据类 Chunk：text、page_num、doc_name、chunk_id、strategy_name
- 抽象基类 ChunkStrategy：类属性 name；方法 chunk(pages, config) 返回 List[Chunk]

### 3. src/chunking/fixed_overlap.py
- 固定token数切分，带重叠（按字符近似，1 token = 2 chars）
- 参数：chunk_size（默认512）、chunk_overlap（默认64）
- 自己实现，不使用LangChain splitter，保证可复现、无隐式随机

### 4. src/chunking/semantic_paragraph.py
- 按段落边界切分，段落累积到 max_chunk_size（默认1024）后断开
- 保留段落间换行符作为分隔

### 5. src/chunking/registry.py
- get_strategy(name) 返回对应策略实例
- 支持 fixed_overlap / semantic_paragraph，未知值抛 ValueError

### 6. tests/test_chunking.py
- 最小单元测试（unittest），覆盖两种策略基本切分行为
