## 本Prompt目标

请生成以下模块的完整可运行Python代码：

### 1. src/embedding/base.py
- 抽象基类 EmbeddingModel：
  - 类属性 model_name（str，如 bge-small）
  - 方法 embed(texts) 返回 List[List[float]]
  - 属性 model_id（str，HuggingFace模型ID）

### 2. src/embedding/bge.py
- BGE-small 实现：model_id = BAAI/bge-small-zh-v1.5
- 使用 SentenceTransformer 加载
- 支持 device=cuda 或 cpu 参数

### 3. src/embedding/minilm.py
- all-MiniLM-L6-v2 实现：model_id = sentence-transformers/all-MiniLM-L6-v2
- 使用 SentenceTransformer 加载
- 支持 device=cuda 或 cpu 参数

### 4. src/embedding/registry.py
- get_embedding(name, device) 返回 EmbeddingModel 实例
- 支持 bge-small / all-minilm-l6-v2，未知值抛 ValueError

### 5. src/vectorstore/faiss_store.py
- 类 FAISSStore：
  - __init__(index_path, dim)
  - add(chunks, vectors)：保存FAISS索引到磁盘
  - search(query_vec, top_k) 返回 List[(chunk_id, score)]
  - 索引文件名：faiss_{model_name}.faiss（与嵌入模型绑定，避免跨模型混用）

### 6. scripts/build_index.py
- 入口：读 config.yaml -> 加载PDF -> 切分 -> 嵌入 -> 建FAISS索引
- 每100个chunk打印一条进度log
