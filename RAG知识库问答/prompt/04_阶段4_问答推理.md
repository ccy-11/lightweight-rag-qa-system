## 本Prompt目标

请生成以下模块的完整可运行Python代码：

### 1. src/retrieval/prompt_template.py
- 定义 RAG_PROMPT_TEMPLATE，结构：
  - System：你是知识库问答助手，仅基于提供的上下文回答，上下文不足时明确说明无法回答
  - User：【上下文】{context_blocks}【问题】{question}
- context_blocks：最多 top_k=5 个chunk，每个含来源标注（doc_name:page_num）
- 提供 build_prompt(question, chunks) 返回 str

### 2. src/retrieval/llm.py
- 类 QwenLLM：
  - __init__(model_id=Qwen/Qwen-1.8B-Chat, device=cuda, use_quantization=True)
  - generate(prompt, max_tokens=512) 返回 str（贪心解码，do_sample=False，temperature=0）
  - 4bit量化：BitsAndBytesConfig（load_in_4bit=True，bnb_4bit_quant_type=nf4）
  - 量化失败时降级到 CPU + 8bit，打印警告，不崩溃

### 3. src/retrieval/qa_pipeline.py
- 类 QAPipeline：
  - __init__(faiss_store, embedding_model, llm, top_k=5)
  - answer(question) 返回 Answer
- Answer dataclass：question、answer、context_chunks、retrieval_time（秒）、generation_time（秒）

### 4. scripts/ask.py
- 交互式CLI：读入用户问题 -> 调用 QAPipeline -> 打印答案 + 来源chunk
- 支持 --config config.yaml 参数
