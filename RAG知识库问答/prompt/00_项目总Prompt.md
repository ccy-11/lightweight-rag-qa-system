# 总纲Prompt：本地RAG知识库问答系统——完整项目开发方案

## 项目背景（上下文）

我准备开发一个轻量级本地RAG知识库问答系统，用于GitHub开源，并基于此写ArXiv预印本，求职AI应用工程师。

**技术栈（严格限定，不要引入额外依赖）：**
- 语言：Python 3.10+
- 框架：LangChain
- 嵌入模型：BGE-small（默认），支持切换 all-MiniLM-L6-v2
- 向量库：FAISS（本地持久化）
- 生成模型：Qwen-1.8B-Chat，通过本地 transformers 推理（4bit量化，贪心解码保证可复现）
- 文档解析：PyPDF2
- 评测指标：Rouge-1/2/L

**运行环境约束：**
- 本地：16GB内存电脑（CPU或带GPU均可）
- Colab：免费tier（GPU可用）
- 所有模型权重需可从HuggingFace下载，不依赖任何商业API

**评测语料：**
- 公开QA数据集（CNS新闻问答集或同级数据集，可下载）
- 附带的示例PDF文档（用于冒烟测试）

**实验目标（消融级别）：**
- 对比两种文本切分策略对Rouge指标的影响
- 对比BGE-small vs all-MiniLM-L6-v2嵌入模型对Rouge指标的影响
- 记录延迟、硬件环境，保证论文可复现
