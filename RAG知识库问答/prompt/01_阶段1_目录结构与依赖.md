# 阶段1 Prompt：项目目录结构 + requirements.txt

## 项目背景（上下文）

轻量级本地RAG知识库问答系统，用于GitHub开源并支撑ArXiv预印本。

**技术栈（严格限定）：**
- Python 3.10+ / LangChain / BGE-small（默认嵌入，支持切 all-MiniLM-L6-v2）/ FAISS（本地持久化）/ Qwen-1.8B-Chat（本地transformers，4bit量化，贪心解码）/ PyPDF2 / Rouge-1/2/L
- 运行环境：Colab 免费tier 或 16GB内存本地电脑
- 模型权重全部从HuggingFace下载，不依赖商业API
- 无Agent、无工具调用、无Web UI

**消融实验维度：**
- 切分策略：fixed_overlap（固定token数重叠切分） vs semantic_paragraph（语义段落切分）
- 嵌入模型：BGE-small vs all-MiniLM-L6-v2
- 评测：公开QA数据集（CNS新闻问答集）+ 示例PDF冒烟测试

**目录结构约定（与总纲一致，不要更改名称）：**
src/（loading/、chunking/、embedding/、vectorstore/、retrieval/、evaluation/）、config.yaml、data/、model_cache/、experiments/、scripts/
