# 阶段7 Prompt：实验记录模板（ArXiv消融实验用）

## 项目背景（上下文）

轻量级本地RAG知识库问答系统（GitHub开源 + ArXiv预印本）。

**消融实验维度：**
- 切分策略：fixed_overlap（512/64） vs semantic_paragraph（1024）
- 嵌入模型：BGE-small（bge-small-zh-v1.5） vs all-MiniLM-L6-v2
- 指标：Rouge-1/2/L（F1）+ 平均检索延迟 + 平均生成延迟 + 总耗时

**可复现要素（论文需要）：**
- 随机种子
- 各库版本号（torch、transformers、faiss-cpu、sentence-transformers、rouge-score）
- 硬件环境（GPU型号 / CPU / 内存）
- Qwen 量化方式（4bit nf4）

**目录结构（与阶段1/5一致）：**
experiments/results/、experiments/logs/、experiments/templates/
