# lightweight-rag-qa-system
A lightweight local knowledge base QA system based on RAG. Uses LangChain, FAISS, BGE embedding and Qwen-1.8B. Code for arXiv preprint, supports PDF/TXT document retrieval question answering. 中文释义：基于 RAG 的轻量本地知识库问答系统，使用 LangChain、FAISS、BGE 嵌入模型与 Qwen-1.8B，为本项目配套 ArXiv 预印本开源代码，支持 PDF/TXT 文档检索问答。
